# Learned

Patterns from Amjad's past decisions, written by Marsam in its own words.

**Read this at session start, together with `approvals/DECISIONS.md`.** The point of this
file is that Amjad should not have to reject the same class of thing twice. After every
`/review`, extract the rule behind each decision and add it here — the rule, not a
transcript. "Rejects renders above ~30 credits unless the video is for a paid campaign" is
a pattern. "Rejected 2026-08-25-03" is not.

Keep it short. A file of fifty half-observed rules is a file nobody applies. When two
entries contradict each other, the newer one wins and the older one gets deleted, not
annotated.
